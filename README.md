## 開始遊玩

1. 開啟 `index.html`（推薦放到 GitHub Pages），選「經典挑戰」或「極速狂歡」。
2. 選「開始砸金蛋」，等待 3、2、1 倒數。
3. 看螢幕裡第幾顆蛋發光，立刻點下方對應的蛋形按鈕。
4. 命中後可能得到金幣得分、虛擬獎券、寶石、金雞、幸運大抽獎，或空蛋扣分。
5. 集滿 3 隻金雞就完成大獎挑戰；時間結束後則計算本局成績。
6. 右上角 `?` 可看完整玩法，喇叭按鈕切音效，底部按鍵暫停／繼續／再玩一局。

## 部署到 GitHub Pages

直接把 **ZIP 解壓後內部所有檔案** 放到儲存庫的網頁根目錄；包括 `index.html`、`game.js`、`styles.css`、`sw.js`、`manifest.webmanifest`、`assets/`。

1. 前往你的 GitHub Repository → **Settings** → **Pages**。
2. Build and deployment 選 **Deploy from a branch**，Branch 選 `main`、Folder 選 `/(root)` 並儲存。
3. 開啟 `https://你的帳號.github.io/你的儲存庫名稱/`。
4. iPhone Safari 點分享 → **加入主畫面**，即可像手機遊戲 App 一樣啟動。

也提供 `lucky-eggs-v2-standalone.html` 獨立版本（完整 CSS/JS/背景已內嵌）。iPhone 的「檔案」預覽可能限制 JavaScript，遇到此情況請改用 Safari 打開 GitHub Pages 網址；不用安裝任何 npm 套件或後端服務。

## 品質檢查與限制

- `node --check game.js` 語法檢查通過。
- Node.js VM 模擬測試通過：倒數、敲擊、獎券、寶石、特殊抽獎、空蛋、金雞 ×3、Jackpot、暫停計時、恢復、極速模式與超時結算。
- Chromium / Playwright 以 **428×926、390×844、375×667** 測試遊戲啟動、介面、開局、遊玩中、無 JavaScript 例外、無視窗外溢與捲動。
- 原機動畫與人物背景只能根據拍攝畫面還原，不保證清晰度和官方素材一致；V2 沒有連接任何真實街機硬體或支付服務。
- 音效採用瀏覽器 Web Audio 合成；第一次操作後才開始播放，音量由裝置控制。
- 最高分只存在同一瀏覽器 `localStorage`，清除網站資料會重置，未提供跨裝置帳號。
- `sw.js` 有版本化快取；若自行修改程式，請更換 `CACHE` 字串以避免裝置顯示舊畫面。
