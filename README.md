# 鑽石球場 ’07｜手機版棒球遊戲

這是受 2007 年 J2ME 棒球遊戲風格啟發、以原創球隊與 Canvas 畫面製作的獨立單機遊戲，非原版商業遊戲，也未使用原版素材。

## 怎麼玩

1. 開啟 `index.html` 即可在桌上型瀏覽器遊玩。
2. 在 iPhone 或 Android 上，建議上傳整個資料夾到 **GitHub Pages**（把 `index.html` 放在儲存庫根目錄；Settings → Pages → Deploy from a branch），再用手機瀏覽網址即可直式觸控遊玩。
3. 選擇 3、6、9 局，或遊玩 10 球全壘打挑戰。
4. 打擊：看投手投球，球接近本壘板時點「揮棒！」；可先選拉打／中間／反向方向。未揮棒時依好壞球判定。
5. 投球：選擇快速球、曲球、變速球及九宮格落點；看準度指針進入綠色範圍時投球。
6. 守備：電腦擊出可接殺的飛球後，在球快落地時按「接球」。
7. 電腦版：空白鍵揮棒／投球／接球，左右鍵選擇打擊方向，P 鍵暫停。

## 技術與限制

- 單檔 HTML/CSS/JavaScript，無外部素材或網路依賴。
- 2.5D Canvas 透視風格，**不是**原版 J2ME 的完整 3D 模型／3D 引擎，也沒有原版 1:1 的 AI、球員、音效與所有細節。
- 攻守換局、B/S/O 計數、安打、四壞球、三振、全壘打、手動接球與計分均實作。
- 單機模式，無線上對戰與 MLB 授權球隊、商標、球員肖像。
- 透過 HTTPS 網址第一次開啟後，可加入手機主畫面（PWA），並可使用離線快取；iOS 如透過「檔案」App 點 HTML 未能正確執行 JavaScript，請以 GitHub Pages 網址在 Safari 開啟。
