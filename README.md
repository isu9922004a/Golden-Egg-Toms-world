# 砸金蛋 Lucky Eggs V3.0.0

純前端免費街機模擬，無真實獎金及實體兌獎；參考使用者上傳的影片中可見流程，非原機程式移植。

## V3 新增

- **街機選蛋**（預設）：顯示六個獎勵 → 洗牌 → 從下方六顆金蛋選一顆 → 逐次開獎，共四回合。
- **大型開獎與幸運大抽獎**：四格票券輪盤，抽到的獎勵記錄在局內總分。
- **模式保留**：V2 的經典反應 60 秒、極速反應 45 秒。
- **操作**：觸控金蛋，或鍵盤 1–6 選蛋；可暫停、背景自動暫停、重來、分享成績。
- iPhone 12 Pro Max 及常見手機版面。

## 安裝到 GitHub Pages

把這個資料夾內 **index.html、game.js、styles.css、manifest.webmanifest、sw.js、assets/** 一起上傳到 Pages 網站根目錄。原先 V2 檔案以同名取代，PWA 快取會更新為 v3。

## 規則與風險揭露

影片只能判斷視覺與流程；0/4 的原始涵義、機台判獎機制、抽獎機率、真實票券演算法無法由影片可靠驗證。本版將 0/4 **定義為手機版四回合**，抽獎結果由手機端隨機模擬。沒有真實獎券、現金、投注、充值或兌獎。
