# 砸金蛋 Lucky Eggs｜手機街機遊戲

版本：v1.0.0 · 2026-10-22

這是根據使用者提供之 60 秒街機實拍影片所製作的 **可遊玩手機網頁遊戲**，不是原街機的程式碼移植，也不是逐像素複製。畫面以使用者提供的影片截圖為參考背景，金蛋控制盤、動畫、觸控規則、音效、獎勵與計分系統則重新實作。原廠遊戲的中獎機率及實際獎項規則無法單憑影片確認，所以此版本採用自行設計的遊戲規則，不涉及真實投幣、兌獎、支付或金錢。

## 玩法

1. 進入遊戲，選擇 **開始砸金蛋**。
2. 每局 60 秒，六顆黃色金蛋會輪流亮起；點擊正在發光的蛋。
3. 敲中會隨機出現金幣、幸運星、寶石、炸彈或金雞；每次獎勵獨立隨機。
4. 集滿 **3 隻金雞** 即挑戰成功；倒數結束前沒集滿則結算得分。
5. 可以暫停、繼續、重新開始；右上角可切換音效。手機可觸控，電腦也可按鍵盤 1～6 操作，空白鍵暫停。
6. 本機保存最高分、試玩代幣與音效選項。代幣可以免費補充，沒有付費機制。

## 不用部署就直接試玩

下載旁邊另外提供的 `lucky-eggs-standalone.html`，它是 **單一 HTML 檔**，不依賴外部網路、CDN 或圖片網址。如果手機的 HTML 預覽程式限制 JavaScript，請改用以下 GitHub Pages 網站部署方式。

## 發布到 GitHub Pages（手機 Safari / Chrome）

1. 解壓縮 `lucky-eggs-mobile.zip`。
2. 將 `lucky-eggs-mobile` 資料夾中的**所有內容**上傳到 GitHub 儲存庫的根目錄（包含 `assets` 資料夾）；或放在儲存庫的一個獨立資料夾中。
3. 進入 GitHub 儲存庫 **Settings → Pages → Build and deployment**，選擇 `Deploy from a branch`，分支選 `main`，資料夾選 `/ (root)`，儲存。
4. 頁面啟用後，開啟 `https://帳號.github.io/儲存庫名稱/`。若放在子資料夾則網址加上子資料夾名稱。
5. iPhone Safari 按分享 → **加入主畫面**，可像一般手機 App 一樣全螢幕開啟；首次載入後支援基本離線存取。

網站以相對路徑設計，適用 GitHub Pages 子路徑。若更新遊戲檔案，請同步變更 `sw.js` 中的快取版本號，避免用戶手機保留舊版。

## 已知與原機差異

- 提供的參考影片是**實體街機的攝影錄影**，帶有視角透視、反光、遮擋，沒有原始的 3D 人物模型、音軌、UI 素材或規則表，因此無法保證 100% 相同。
- 這個版本以原片截圖保留角色與主機遊戲畫面的視覺印象，其餘操控面板與動畫為自主重建。
- 獎勵分布（含金雞 12% 觸發機率）為本遊戲程式參數，**不代表原街機設定**。
- 遊戲僅供娛樂試玩，沒有真實獎勵、金流或賭博用途。
